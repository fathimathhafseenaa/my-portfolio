## ⚙️ Run Locally

### Prerequisites
- Node.js and npm
- Git

### Installation

```bash
git clone https://github.com/fathimathhafseanaa/my-portfolio.git
cd my-portfolio
npm install
npm run dev
```

Open the local URL displayed in your terminal to view the portfolio.
